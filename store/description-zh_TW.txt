在本機處理滑鼠手勢，不儲存輸入，不進行追蹤。

按住滑鼠右鍵，畫出手勢後放開：
← 向左：返回
→ 向右：前進
↓→ 先向下再向右：關閉目前分頁

在同一位置、300 毫秒內按兩次右鍵，即可開啟原生選單。單次右鍵點擊用於手勢輸入。按 Escape 可取消進行中的手勢。

特色：
- 僅在記憶體中暫時處理手勢所需的滑鼠座標、時間和 Escape 取消輸入，並顯示軌跡與操作提示
- 不儲存輸入或瀏覽紀錄、不進行追蹤或分析、不向外部傳輸資料
- 完整開源，可重現封裝並執行自動檢查
- 不要求 tabs、storage、cookies 或 history API 權限
- 支援英文、韓文、簡體中文及繁體中文

擴充功能需要網站存取權限，才能在支援的頁面與內嵌框架中偵測滑鼠輸入並顯示提示。Chrome 可能提示擴充功能可以讀取及變更網站資料；這項存取僅用於本機手勢處理。返回與前進仍會像一般瀏覽器導覽一樣載入網站。

Chrome 內部頁面、Chrome 線上應用程式商店、其他擴充功能頁面及內建 PDF 檢視器不支援手勢。本機檔案與無痕視窗須在 Chrome 設定中另行允許。原生選單事件的時機可能因作業系統與輸入裝置而異。如果與網站自身的右鍵功能衝突，可在 Chrome 中限制本擴充功能的網站存取權限。
