Mouse gestures processed locally, with no tracking or input storage.

Hold the right mouse button, draw a gesture, and release:
← Left: Go back
→ Right: Go forward
↓→ Down then right: Close the current tab

To open the normal context menu, right-click twice in the same spot within 300 ms. Press Escape to cancel a gesture. A single right-click is reserved for gesture input.

Features:
- Gesture-related mouse coordinates, timing, and Escape cancellation input are processed temporarily in memory, with visible trail and action feedback
- No input or browsing history storage, tracking, analytics, or external data transmission
- Open source, with reproducible packaging and automated checks
- No tabs, storage, cookies, or history API permissions
- English, Korean, Simplified Chinese, and Traditional Chinese

Website access is required to detect mouse input and draw feedback on supported pages and embedded frames. Chrome may warn that the extension can read and change website data; this access is used locally for gestures. Back/forward navigation loads websites normally.

Chrome internal pages, the Chrome Web Store, other extensions' pages, and the built-in PDF viewer are restricted. Local files and incognito windows need separate permission in Chrome settings. Native context-menu timing can vary by platform and input device. If a website's own right-button controls conflict, restrict this extension's site access in Chrome.
