마우스 입력을 기기 안에서 처리하고 저장하거나 추적하지 않는 제스처 확장프로그램입니다.

마우스 오른쪽 버튼을 누른 채 방향을 그린 뒤 놓으세요.
← 왼쪽: 뒤로가기
→ 오른쪽: 앞으로가기
↓→ 아래로 이동한 뒤 오른쪽: 현재 탭 닫기

기본 컨텍스트 메뉴는 같은 위치에서 300 ms 이내로 2번 우클릭하면 열립니다. 일반 우클릭 1회는 제스처 입력용입니다. Escape로 진행 중인 제스처를 취소할 수 있습니다.

특징:
- 제스처용 마우스 위치·시간과 Escape 취소 입력을 메모리에서 일시적으로 처리하고 궤적·동작 안내 표시
- 입력·탐색 기록 저장, 추적, 분석, 외부 데이터 전송 없음
- 소스 공개, 재현 가능한 패키징, 자동 검증
- tabs, storage, cookies, history API 권한을 요청하지 않음
- 한국어, 영어, 중국어 간체와 번체 지원

웹 페이지와 지원되는 프레임의 마우스 입력을 감지하고 안내를 표시하기 위해 사이트 접근 권한을 사용합니다. Chrome에서 사이트 데이터를 읽고 변경할 수 있다는 경고가 표시될 수 있으며, 이 접근은 제스처를 위한 로컬 처리에 사용됩니다. 뒤로가기·앞으로가기에 따른 웹사이트 자체의 통신은 일반 브라우저 탐색과 같습니다.

Chrome 내부 페이지, 웹 스토어, 다른 확장프로그램의 페이지, 내장 PDF 뷰어에서는 동작하지 않습니다. 로컬 파일과 시크릿 모드는 Chrome 설정에서 별도로 허용해야 합니다. 운영체제와 입력 장치에 따라 기본 메뉴의 이벤트 시점이 다를 수 있습니다. 사이트의 자체 우클릭 기능과 충돌하면 Chrome에서 이 확장프로그램의 사이트 접근을 제한하세요.
