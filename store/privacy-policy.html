Simple Mouse Gestures - Privacy Policy

Last updated: 2026-10-13

Local processing

Simple Mouse Gestures temporarily accesses and uses user-activity input locally in your browser: gesture-related mouse coordinates, button events, timing, and directions, plus Escape input to cancel a gesture. This processing provides navigation, tab closing, the gesture trail, and double-right-click menu behavior. It does not record the text you type or perform general keystroke logging.

This input is handled in memory only. It is not logged, written to persistent storage, or transmitted outside your browser. Temporary interaction state is replaced or cleared during gesture processing and is lost when the page or browser worker closes.

Data use and transmission

The extension does not store input or browsing history, and does not use cookies, activity tracking, analytics, telemetry, advertising, remote code, or third-party network services. It does not share or sell the input it processes. The developer and third parties do not receive or have access to this input through the extension.

The extension makes no requests to external servers. Back and forward gestures use normal browser navigation, which may cause the websites you visit to load content as usual.

Limited use

User-activity input is used solely for the disclosed mouse-gesture functionality, in accordance with the Chrome Web Store User Data Policy, including its Limited Use requirements. It is never used for advertising, profiling, creditworthiness, or unrelated purposes. The developer does not receive, access, or manually read this input.

Website access and permissions

The extension declares a content script for all supported website URLs and matching embedded frames. This site access lets it listen for mouse events and draw a gesture trail and feedback in the page DOM. Chrome may display a warning that the extension can read and change website data. You can restrict site access through Chrome's extension settings.

The extension requests no additional API permissions. In particular, it does not request the tabs permission: closing the tab that sent the gesture uses chrome.tabs.remove(), which does not require that permission. No storage, cookies, history, or network interception API permissions are requested.

Chrome restricts content scripts on internal pages, the Chrome Web Store, other extensions' pages, and its built-in PDF viewer. Local file access and incognito access require separate user settings in Chrome.

Open source

The complete source code is available in the GitHub repository. The release archive is generated from a fixed allowlist, and automated checks verify that its runtime files match the source.
