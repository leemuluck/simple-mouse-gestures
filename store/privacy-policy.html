Simple Mouse Gestures - Privacy Policy

Last updated: 2026-10-13

Local processing

Simple Mouse Gestures recognizes mouse gestures locally in your browser. Mouse coordinates, timing, and gesture directions are processed temporarily in memory. This input is not saved or sent to a server.

Data collection and transmission

The extension does not collect or persist personal data or browsing history, and does not use cookies, analytics, telemetry, advertising, remote code, or third-party network services. It does not share or sell user data.

The extension makes no requests to external servers. Back and forward gestures use normal browser navigation, which may cause the websites you visit to load content as usual.

Website access and permissions

The extension declares a content script for all supported website URLs and matching embedded frames. This site access lets it listen for mouse events and draw a gesture trail and feedback in the page DOM. Chrome may display a warning that the extension can read and change website data. You can restrict site access through Chrome's extension settings.

The extension requests no additional API permissions. In particular, it does not request the tabs permission: closing the tab that sent the gesture uses chrome.tabs.remove(), which does not require that permission. No storage, cookies, history, or network interception API permissions are requested.

Chrome restricts content scripts on internal pages, the Chrome Web Store, other extensions' pages, and its built-in PDF viewer. Local file access and incognito access require separate user settings in Chrome.

Open source

The complete source code is available in the GitHub repository. The release archive is generated from a fixed allowlist, and automated checks verify that its runtime files match the source.
