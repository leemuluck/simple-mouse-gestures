在本地处理鼠标手势，不保存输入，不进行跟踪。

按住鼠标右键，画出手势后松开：
← 向左：后退
→ 向右：前进
↓→ 先向下再向右：关闭当前标签页

在同一位置、300 毫秒内右键点击两次，即可打开原生菜单。单次右键点击用于手势输入。按 Escape 可取消正在进行的手势。

特点：
- 仅在内存中暂时处理手势所需的鼠标坐标、时间和 Escape 取消输入，并显示轨迹与操作提示
- 不保存输入或浏览历史，不进行跟踪或分析，不向外部传输数据
- 完全开源，可复现打包并进行自动检查
- 不请求 tabs、storage、cookies 或 history API 权限
- 支持英语、韩语、简体中文和繁体中文

扩展需要网站访问权限，才能在受支持的页面和嵌入框架中检测鼠标输入并显示提示。Chrome 可能提示扩展可以读取和更改网站数据；此访问仅用于本地手势处理。后退和前进仍会像普通浏览器导航一样加载网站。

Chrome 内部页面、Chrome 网上应用店、其他扩展页面及内置 PDF 查看器不支持手势。本地文件和无痕窗口需要在 Chrome 设置中单独允许。原生菜单事件的时机可能因操作系统和输入设备而异。如果与网站自身的右键功能冲突，可在 Chrome 中限制此扩展的网站访问权限。
